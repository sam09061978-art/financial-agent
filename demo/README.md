# Демонстрация: конвейер «утро» на синтетических данных

Реальные данные компании не публикуются — комплект в `demo-data/` сгенерирован генератором
(`scripts/make-demo-data.js`) и полностью согласован между собой: суммы выписки, реестров,
журнала заявок и базы перечня бьются с контрольными равенствами.

## Сюжет демо

- Дата цикла: **18.01.2027** (перечень на утро), выписка за 17.01.
- Вчера оплачено: ИП Иванов 28 400 + ЭлектроПлюс 15 480 = **43 880** (видно в выписке).
- Реестр №2907 (утверждён): остаток бетон **212 900** (3 сч.ф.).
- Реестр №2908 (на утверждении): **131 578,10** (5 позиций); контроль шапки «Сумма неоплаченных реестров» = 344 478,10.
- Новые заявки 17.01: АвтоНорма 6 489,30, ЧистоБаза 3 600 (на 20.01), ВодаПлюс 1 425 (на 23.01).
- Депозитные обороты (вклад 5 млн, возврат + проценты) и комиссия 70 ₽ — вне перечня (сверяются в отчёте).

## Шаги прогона

```bash
# 0) (опционально) перегенерировать комплект «утро»
node scripts/make-demo-data.js

# 1) сборка перечня через Excel COM (Windows + установленный Excel)
cscript //nologo scripts/build-register-com.wsf demo/register-data.json demo-output/unpaid-payments-register.xlsx

# 2) независимая верификация артефакта (Node + SheetJS)
node scripts/verify-register.js

# 3) monthly-контур: синтетический журнал 1С → матрица «статья × ЦФО»
node scripts/make-demo-bdr-data.js
node scripts/build-bdr-demo.js

# 4) итоги
start demo-output/unpaid-payments-register.xlsx
start demo-output/bdr-stroykom-01.2027.xlsx
```
