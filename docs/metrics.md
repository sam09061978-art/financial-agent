# Метрики и доказательства

Собрано по журналам эксплуатации в основной рабочей папке (октябрь–ноябрь 2026, реальные данные компании; в публичном репозитории публикуется только свод, без исходных файлов).

## Скорость

| Операция | До (вручную) | После (конвейер) |
|---|---|---|
| Ежедневная сводка «утро» (4 файла → перечень + отчёт) | ~1–2 часа | ~5 минут (в т.ч. 2 контрольных прогона) |
| Месячная раскладка БДР по ЦФО (журнал ~2 800–3 500 проводок) | 1–2 рабочих дня | ~30–40 минут на полный прогон с верификацией |

## Надёжность

- Расхождение сверки выписки за все рабочие дни эксплуатации (26.10.2026–18.11.2026): **0,00** — сверка копейка в копейку каждый день;
- Пример: день 17.11.2026 — контрольный итог 36 786 290,30, расхождение 0,00; перечень 2 332 999,17 по 29 заявкам, формулы и итоги сошлись в трёх независимых проверках;
- Квартальный свод БДР: 29 правил постстрочного контроля × 3 месяца — 0 расхождений; непокрытый остаток разнесения — 0,00 (полный контроль каждой проводки).

## Контрольная архитектура

1. Самопроверка сборщика (COM): контрольные суммы до записи книги, падение при расхождении;
2. Независимый верификатор (Node/SheetJS): листовые формулы, итоги, колонки дат, автофильтр;
3. Сверка с первоисточником: банковская выписка «поступления + списания = контрольный итог файла»;
4. Журнал проверки прикладывается к каждому артефакту (пример: demo-output/verification-report.md).
