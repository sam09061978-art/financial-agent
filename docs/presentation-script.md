# Выступление на выпускном (3–5 минут) — сценарий

**Проект: «Финансовый агент строительной компании»**

**Ссылки для показа:**

- Витрина (интерактив, 4 страницы): https://sam09061978-art.github.io/financial-agent/

## 0:00 — Название и описание (30 сек)

«Мой проект — финансовый агент строительной компании. Это конвейер, который каждое утро из четырёх выгрузок — банковской выписки, реестров платежей, журнала заявок и перечня из 1С — за минуты собирает список платежей к оплате, полностью свёртый по суммам. Раз в месяц тот же подход собирает бюджет доходов и расходов по подразделениям и дашборд для руководителя».

## 0:30 — Проблема (45 сек)

«Финансист в строительной компании тратит 1–2 часа каждое утро на ручную сводку: кто оплачен, кто в реестрах на утверждении, что пришло новое. Ошибка на копейку ищется потом часами. И раз в месяц всё это повторяется в масштабе месячного БДР. Проект убирает рутину и добавляет автоматический контроль сумм — расхождения либо ноль, либо сразу видно где».

## 1:15 — Живая демонстрация (2 мин)

Два варианта показа — по скриншотам из папки screens/ или онлайн-витриной (браузер):

**По витрине (быстрее, стабильнее):**
1. (pages/utro.html) «Вот перечень платежей к оплате на утро 18 января: 561 тыс. рублей, 17 заявок, статусы реестров, план оплат по дням — интерактив, фильтры по статусам»;
2. (pages/proverki.html) «Сразу после сборки работают независимые проверки: суммы колонок сходятся с итогом, формулы на месте — расхождение ноль»;
3. (pages/bdr.html) «Раз в месяц тот же контур собирает БДР по подразделениям: журнал проводок 1С — правила разнесения — матрица статья×ЦФО; каждая статья раскрывается в проводки, внизу — контроль Σ матрицы = Σ журнала»;
4. (dashboard/index.html) «И дашборд руководителя: деньги дня и бюджет года на одном экране».

**По скриншотам (если нужен живой Excel):**
1. (ск 1) «Вход: четыре сырых файла. Вот выписка и реестр — обычные 1С-выгрузки»;
2. (ск 2) «Одна команда — конвейер — собирает итоговый Excel: перечень платежей к оплате, живые формулы сумм, итоги по реестрам и общий итог — файл можно резать и фильтровать»;
3. (ск 3) «Сразу после сборки — независимая проверка. В реальной эксплуатации — больше 20 рабочих дней подряд, расхождение с выпиской — ноль»;
4. (ск 4) «БДР по подразделениям из выгрузок 1С — матрица с живыми формулами итогов»;
5. (ск 5) «Дашборд руководителя: деньги дня и бюджет года».

## 3:15 — Результаты (45 сек)

«Что на выходе: Excel-перечень с формулами и группировкой, отчёт дня с контрольными суммами, книга БДР по ЦФО с листом «требует решения», дашборд. Каждый артефакт проходит независимую проверку отдельным скриптом. Скорость: 1–2 часа ручной работы → минуты. Репозиторий полный — можно забрать и запустить на своих данных: в демо-комплекте лежит синтетический набор, конвейер работает без реальных цифр компании. Есть skill для Claude Code — коллега разворачивает сценарий один в один у себя».

## Если спросят

- **«А если данные отличаются?»** — правила разнесения прописаны декларативно (смета правил), агент адаптирует под ваш формат источников.
- **«Насколько это сложно повторить?»** — скилл + инструкция на синтетике: три команды от нуля до артефакта; скилл можно открыть прямо по ссылке.
- **«Почему Excel?»** — это интерфейс пользователя; формулы и группировки остаются живыми, файл можно спокойно править руками.
- **«А данные настоящие?»** — в демо — полностью синтетические (объекты М1/М2, контрагент «СтройКом»); в реальной эксплуатации конвейер работает на настоящих выгрузках более 20 рабочих дней, показываю по витрине.
